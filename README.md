# Ghostlight Arcade

**2D Platformer · 3D Scene · QA Test Design**

以森林幽灵场景和樱桃闯关小游戏为主题的多媒体课程作品展示，面向游戏测试／软件测试实习。作品包含跟随教程学习与复现的内容，课程作业于 2026 年 6 月完成。

当前保留了 Windows 成品和课程报告，原始工程尚未找回。本仓库整理作品预览、技术线索和 22 条待执行测试用例，适合展示课程实践与测试设计思路。

## 作品预览

### Ghostlight Grove｜森林幽灵场景

![森林幽灵场景，来自原课程报告第 9 页](docs/images/scene-report.png)

以多张 2D 图片在 3D 空间中组合出纵深，搭配树木、地面、长椅和小幽灵。课程报告记录了幽灵骨骼动画、面向镜头的精灵效果，以及光点、薄雾粒子。后续测试重点是镜头移动与边界、精灵朝向、动画及粒子显示。

### Cherry Run｜樱桃平台闯关

![樱桃平台闯关，来自原课程报告第 15 页](docs/images/platformer-report.png)

玩家移动、跳跃、收集樱桃并避开陷阱，到达终点后切换关卡。构建文件保留了开始页、两关和结束页的场景记录，可围绕碰撞、计数、死亡重试和场景切换设计测试。

两张图片均提取自原课程报告，属于历史作品画面；本次整理未重新采集运行截图。

## 现有材料与运行方式

完整 Windows 成品仍保存在本地原课程提交目录，未改动或重新打包；本仓库不提供成品、原始报告或日志下载。

1. 使用完整 Windows 成品目录。
2. 2D 作品启动 `I am a man.exe`；3D 作品启动 `scenesample.exe`。
3. 保留同级 `TuanjiePlayer.dll`、`MonoBleedingEdge` 和对应的 `*_Data` 目录，运行时需要这些文件。
4. 先确认操作键位和实际规则，再依据测试用例记录环境、步骤、结果与截图。

两份成品分别约 108.22 MiB 和 134.65 MiB。原工程缺失，因此暂时无法在编辑器中修改、重新导出或生成 WebGL 版本。教程、素材和字体来源仍在补充，本仓库未设置覆盖整个作品的统一开源许可证。
